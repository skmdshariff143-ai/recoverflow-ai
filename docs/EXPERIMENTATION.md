# RecoverFlow AI — Experimentation & Contextual Bandit Governance

## 1. Thompson Sampling Architecture
The Margin Guardian dynamically selects incentive and recovery channels among policy-eligible safe actions using Beta-Bernoulli Thompson Sampling:
$$\\theta_k \\sim \\text{Beta}(\\alpha_k, \\beta_k)$$
$$\\text{Arm}^\\ast = \\arg\\max_k \\left( \\theta_k \\times \\text{ExpectedMargin}(k) - \\text{Cost}(k) \\right)$$

## 2. Policy-Safe Action Containment
- The bandit may only sample from **pre-approved safe candidate actions** generated by deterministic policy.
- Hard margin floors (e.g. minimum 20% gross margin) and discount ceilings (e.g. maximum 15%) are strictly enforced in TypeScript before arm selection.
