## 1. Classification Definitions

| Classification | Meaning |
| :--- | :--- |
| **`IMPLEMENTED_AND_VERIFIED`** | Working code, automated tests (unit/integration/E2E), and runtime validation exist and pass against durable production infrastructure (PostgreSQL 16, Redis 7, and Docker worker containers). |
| **`IMPLEMENTED_NOT_FULLY_VERIFIED`** | Working code and internal contract tests exist, but full verification is pending external live third-party provider accounts (e.g. live Meta WhatsApp Cloud API credentials, live Shopify App Store installation). |
| **`PARTIALLY_IMPLEMENTED`** | Code structure, pure logic, or in-memory prototype exists, but genuine PostgreSQL persistence, distributed Redis queues, or durable crash-recovery is in progress. |
| **`DESIGN_ONLY`** | Specified in documentation or ADRs, but no active executable runtime implementation exists in code. |
